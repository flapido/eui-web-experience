# Requirements review — HIPNOSIS Web Experience

## Sources reviewed

Owner mandate; repository lifecycle and README; supplied Spotify and YouTube URLs; verified EUI release metadata from Bandcamp and Apple Music.

## Decision record

- Implement as a local interactive artist experience, not a generic portfolio or external-player wrapper.
- Make HIPNOSIS the primary identity; keep EUI as a secondary related-project section.
- Prioritize the supplied physical-music visual language: sleeve, vinyl, light palette, silhouettes and contemplative pacing.
- Keep factual copy to EUI, HIPNOSIS, the verified 2017 *EUI* release and verified 2024 *Umbral* single.
- Use explicit demo labels for all non-official visual and audio material.
- Treat external services as destination links rather than embedding or reproducing their media.

## Scope checks

No conflicting product requirements block V1. Owner imagery is absent, so the CSS-generated object and silhouette treatment applies. The requested visual references are translated into original CSS geometry, not copied artwork. The delivery excludes deployment and merge as instructed.

## Recommendation

Proceed with the documented V1 and validate the resulting running interface across the responsive matrix.
